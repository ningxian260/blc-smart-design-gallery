# BLC S.M.A.R.T. 介面設計方案展覽

靜態方案展示網站，整理 58 款本校設計方案、3 款國際風格參考。

## 功能

- 八個分類（七個主風格及一個國際參考分類）、名稱／編號搜尋、電腦／手機及頁面切換。
- 獨立方案連結、圖片放大及完整像素 WebP 圖片。
- 最多三款並排比較，圖片資料缺少時明確標示。
- 此裝置收藏、逐款備註、匯出文字討論清單。
- 手機、平板及電腦排版。

收藏及備註保存在訪客裝置的 localStorage；沒有後端收集或跨裝置同步。

## 預覽

在此資料夾執行 `python3 -m http.server 8765`，再開啟 `http://localhost:8765`。
亦可直接打開 `index.html`。

## GitHub Pages

這個資料夾可以直接成為獨立儲存庫根目錄，不需要 Node.js 建置流程。
推送 `main` 後，可在儲存庫 Settings → Pages 中選擇從 `main` 根目錄發佈。
一般 GitHub Pages 網站會公開，私人原始碼儲存庫不等於私人網站。

## 內容

- `catalog.js`、`catalog.json`：公開方案索引，不含本機路徑。
- `assets/images/`：318 張去重後圖片及各自的縮圖。
- 原始 PNG 另存於本機分類圖片資料夾，沒有放入網站。
